# Hatch

**夢の種を、現実に孵すためのインキュベーター。**

Hatch は、個人の中にある「いつかやりたい」「試してみたい」という夢の種を、小さな行動と実験を通じて育て、現実の成果へつなげる仕組み。

## 基本の流れ

1. **夢の種を置く** — まだ曖昧な願いやアイデアも登録できる。
2. **小さなクエストにする** — いま試せる、負担の小さい一歩に分ける。
3. **現実で試す** — 完成を待たず、実験や体験を通じて確かめる。
4. **記録して振り返る** — 発見、学び、変化を残し、次の一歩を見つける。
5. **孵化させる** — 作品、活動、習慣、企画、出会いなど、現実に生まれたものとして形にする。

## 設計の原則

- 夢が最初から明確である必要はない。
- 大きな目標より、実行できる小さな一歩を大切にする。
- 失敗は評価ではなく、次の試行に使う情報とする。
- 続けることや完成を強制しない。休止や方向転換も認める。
- 夢の持ち主が、何をどこまで共有するかを決める。

## KOUとの関係

Hatch は、**ひとりの夢が育ち、孵化するプロセス**を扱う。

KOU は、人々が互いの夢を応援し、知恵・時間・技術・場所・縁を持ち寄るためのつながりを扱う。

Hatch が夢を育てる仕組みなら、KOU はその道のりを一緒に歩く仲間をつくる仕組み。
